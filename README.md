# Audio Visualizers

Generative audio visualizers by Hans Sai. Each piece synthesizes its own
audio live in the browser (Web Audio API, no samples) and renders visuals
directly from the real-time frequency data.

Live: https://builtbysai.github.io/audio-visualizers/

## Pieces

- **Flux** (`flux/`) — flow-field particle system driven by generative ambient.
  Bass steers currents, mids stir turbulence, highs scatter sparks.
- **Kaleido** (`kaleido/`) — twelve-fold kaleidoscope on a synthesized groove.
  Drag to bend the symmetry.

## Notes

- Audio starts on first tap (browser autoplay policy).
- Everything runs client-side; no backend, no tracking.
